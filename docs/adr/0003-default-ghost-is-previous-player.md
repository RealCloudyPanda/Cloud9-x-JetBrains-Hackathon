# 3. The default rival is the previous player, not the record holder

Each player races the Relay Ghost (the person just before them) by default; the Champion Ghost is opt-in. The record becomes unbeatable for most visitors within an hour, while the previous player is usually beatable and often still standing there, which drives the queue's social energy; the trade-off is that the attract screen and the Leaderboard Monitor must explain two kinds of rival.
